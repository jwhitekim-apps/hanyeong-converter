# 한영타 변환기

한영 전환을 잊고 입력한 글자를 고쳐 주는 Chrome 확장 프로그램입니다. 선택한 텍스트를 두벌식 자판 기준으로 한글 ↔ 영문으로 바꿉니다.

```text
dkssud → 안녕
안녕 → dkssud
```

## 시작하기

1. 저장소를 내려받습니다. ZIP으로 받았다면 압축을 풉니다.
2. Chrome의 `chrome://extensions`에서 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드**에서 저장소 루트(`manifest.json`이 있는 폴더)를 고릅니다.
4. 일반 웹페이지를 새로고침하고, 입력창에 `dkssud`를 입력한 뒤 선택합니다. **우클릭 → 한영타 변환**을 누르면 `안녕`으로 바뀝니다.
